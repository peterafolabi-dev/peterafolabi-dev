oja-ledger.vercel.app
2026 · Fintech · Own product

Oja Ledger

Offline double-entry bookkeeping for Nigerian traders. Record a sale in two taps with no network, and get profit, VAT returns and the small-company tax check under the Nigeria Tax Act 2025.

the hard part

Every entry is sealed with a SHA-256 hash of the one before it, so editing any past naira is detectable. Money is integer kobo, never floats.

Property-based tests throw 800 random trading histories at the engine on every push and prove the books always balance.

Travel & Stays

A two-sided marketplace for verified stays and local tours across Nigeria, with guests, hosts and tour guides, Paystack payments in naira and an admin dashboard.

the hard part

How I work

Guarantees go in the database

If something must never happen, like a double booking or a double payout, I make the database refuse it instead of hoping every code path remembers to check.

Never trust the browser with money

Prices are worked out on the server and every payment is verified with the provider, to the exact amount, before anything is marked paid.

Write down the why

Every project has CI, tests for the parts that matter, and a case study explaining the trade-offs, so the next engineer doesn't have to guess.
